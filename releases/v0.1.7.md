# WYCODE v0.1.7 — assessment usability

The home screen now offers Chat, Assess project, and Assess target with editable prompts. `/chat` explicitly stays in chat; local filenames and file/line references no longer accidentally start assessments. Assess project follows the selected directory after `/cd`.

Assessments show task counts, active and blocked work, and retry reasons. Recorded progress restores when reopening sessions, including when the latest plan is on an older message page. Headless output also exposes progress and blockers.

Reports provide severity filtering, individual evidence, and the original full report through clickable controls and `/findings`, `/evidence`, and `/report`. New finding notes require a valid severity and evidence; rejected updates preserve the existing note. Historical notes remain readable, and unverified candidates remain separate from findings.

## Install or update

Rerun the existing installer to download the latest release and verify its checksum:

```sh
curl -fsSL https://raw.githubusercontent.com/capibaras001/wycode/main/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/capibaras001/wycode/main/install.ps1 | iex
```

The existing GNU Bash >=5.2 requirement and package-manager provisioning remain unchanged. No installer logic change was needed: both installers resolve the latest release dynamically. To select this release explicitly, set `WYCODE_VERSION=v0.1.7` (PowerShell: `$env:WYCODE_VERSION = 'v0.1.7'`).
